# Поиск по вкладкам

Расширение для Яндекс Браузера и Chrome (Manifest V3): быстрый поиск по открытым вкладкам текущей группы или окна. План развития — [PLAN.md](PLAN.md).

## Что умеет (v0.3.0)

- Popup по `Ctrl+Shift+K` (на macOS `Cmd+Shift+K`) или по кнопке на панели.
- **При открытии** — только вкладки текущей группы, справа налево по полосе вкладок: недавно открытые (они справа) сверху, закреплённые 📌 в конце. Активная вкладка выделена и прокручена в центр. Если браузер не отдаёт группу (нет `chrome.tabGroups` или вкладка вне группы) — вкладки текущего окна; причина написана под строкой поиска.
- **При поиске** — сначала совпадения в текущей группе, потом в других группах и окнах. У чужих вкладок подписано, где они лежат: «группа «…»», «другое окно» или «вне группы».
- Поиск по заголовку, домену и URL: регистр не важен, все слова запроса должны совпасть, совпадения в заголовке и в начале слова выше.
- **Возврат назад.** Расширение запоминает вкладку, с которой ты ушёл через поиск:
  - строка «↩ Вернуться: …» вверху popup (выбрана по умолчанию, так что `Cmd+Shift+K`, `Enter` — тоже возврат);
  - отдельная клавиша `Ctrl+Shift+L` (на macOS `Cmd+Shift+L`). Повторное нажатие прыгает обратно, как Alt+Tab.
- `↑`/`↓` — выбор, `Enter` — перейти, `×` при наведении — закрыть вкладку. Клавиатурного закрытия нет специально.
- «Диагностика» внизу popup копирует в буфер JSON: что браузер отдаёт расширению о вкладках, окнах и группах.

## Установка для теста

1. Открой `browser://extensions` (в Chrome — `chrome://extensions`).
2. Включи «Режим разработчика».
3. «Загрузить распакованное расширение» → выбери папку `extension/`.
4. Если горячая клавиша не назначилась (конфликт), задай её на `browser://extensions/shortcuts`.

После правок кода нажми «Обновить» на карточке расширения.

## Что известно о Яндекс Браузере (проверено 15.10.2026, YaBrowser 26.8)

- `chrome.tabGroups` есть, но **группы Яндекса через него не видны**: `tabGroups.query({})` пустой, у всех вкладок `groupId = -1`.
- Зато к каждой вкладке Яндекс добавляет **нестандартное поле `spaceId`** — это и есть его группа (в логе сессии браузера группы тоже называются `space`). По нему расширение определяет текущую группу ([extension/spaces.js](extension/spaces.js)).
- **Названий групп в API нет.** Чужие группы подписаны по содержимому: два самых частых сайта и число вкладок, плюс цветная точка, стабильная для группы.
- Закреплённые вкладки видны в любой группе окна, поэтому считаются текущими.
- `chrome.tabs.query` отдаёт вкладки всех групп окна одним рядом: закреплённые, потом группа за группой.
- Переход на вкладку из другой группы просто **переключает группу** в окне, ничего не закрывается. «Вернуться» переключает обратно.
- Если `spaceId` нет (Chrome или другой браузер), работает `chrome.tabGroups`, а без групп — текущее окно.

Горячие клавиши, если конфликтуют: `browser://extensions/shortcuts`.

## Как это выглядит в Chrome (проверено 15.10.2026, Chrome 151)

- `spaceId` нет, работают стандартные группы: `chrome.tabGroups` отдаёт название, цвет и признак свёрнутости.
- Активная вкладка в группе — в списке только эта группа, на кнопке её название и цвет (в Chrome ещё не проверено руками, только в превью).
- Активная вкладка вне группы — всё окно; вкладки из групп помечены «группа «…»» с цветом группы.

## Разработка

```bash
npm test
```

Юнит-тесты поиска и групп Яндекса (`extension/search.js`, `extension/spaces.js`) на встроенном `node:test`, зависимостей нет.

```bash
npm run preview
```

Затем открой <http://localhost:8765/dev/preview.html> — popup с подменой `chrome.*` ([dev/mock-chrome.js](dev/mock-chrome.js)). Параметр `?yandex` — как в Яндексе: `tabGroups` пустой, группы приходят через `spaceId`. `?nogroups` и `?ungrouped` показывают откат на окно. Строка «Вернуться» появится, если в `sessionStorage` страницы лежит `returnTo` с id другой вкладки.

```bash
npm run zip
```

Собирает `tab-search.zip` для загрузки в магазин.

## Структура

- `extension/manifest.json` — манифест, разрешения `tabs` и `tabGroups`, горячая клавиша.
- `extension/search.js` — поиск и подсветка, без `chrome.*`.
- `extension/spaces.js` — группы Яндекса по `spaceId`: сводка и подписи.
- `extension/scope.js` — текущая группа, переходы с запоминанием «откуда», закрытие вкладок, диагностика.
- `extension/background.js` — горячая клавиша «вернуться назад».
- `extension/popup.{html,js,css}` — интерфейс, светлая и тёмная тема.
