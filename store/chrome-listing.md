## Вкладка Store listing

- **Название:** Поиск по вкладкам (берётся из манифеста).
- **Краткое описание:** берётся из манифеста (лимит 132 символа).
- **Подробное описание:** текст из [opera-listing.md](opera-listing.md), разделы «Русский» и «English», с одной заменой: в 1.2.1 нет клавиши `Ctrl+Shift+L`, поэтому абзац про возврат такой. Chrome показывает описание простым текстом, маркеры «-» оставляем.
  - RU: «Вернуться назад: расширение помнит вкладку, с которой вы перешли через поиск. Строка «Вернуться» стоит первой в списке — Enter возвращает назад.»
  - EN: «Go back: the extension remembers the tab you came from via search. The "Go back" row is first in the list, so Enter takes you back.»
- **Категория:** Productivity.
- **Язык:** русский основной; английское описание добавить как перевод. Интерфейс пока только русский, об этом сказано в английском тексте.

## Вкладка Privacy practices

**Single purpose (назначение):**

> Поиск открытых вкладок браузера по заголовку и адресу и быстрое переключение на найденную вкладку.

**Обоснование разрешений** (по одному полю на каждое):

- `tabs` — получить список открытых вкладок (заголовок, адрес, значок, окно, положение, закреплена ли, время последнего просмотра для сортировки «Активность») для показа и поиска в окне расширения, переключиться на найденную вкладку и закрыть вкладку по кнопке «×». Данные нигде не сохраняются и никуда не отправляются.
- `tabGroups` — прочитать названия и цвета групп вкладок, чтобы показывать вкладки текущей группы и подписывать, в какой группе лежит найденная вкладка.
- `storage` — запомнить номер вкладки, с которой пользователь перешёл через поиск, для функции «Вернуться» (сессионное хранилище, при закрытии браузера пропадает), отметку, что пользователь прочитал уведомление при первом запуске, и выбранный способ сортировки (два значения, без данных о вкладках).

**Host permissions:** не используются. **Remote code:** нет, весь код в пакете, без минификации и сторонних библиотек.

**Раскрытие данных.** Правила Chrome требуют раскрывать обработку данных, даже если они остаются на устройстве, а политика обязательна. Расширение читает адреса и заголовки вкладок — это история просмотров. В форме нужно:

- отметить категорию про историю просмотров / веб-активность (точное название смотри в форме, оно может отличаться);
- подтвердить три стандартных заявления: данные не продаются, не используются не по назначению, не используются для оценки кредитоспособности;
- указать ссылку на политику конфиденциальности (она в репозитории).

Уведомление в интерфейсе: при первом запуске окно показывает, что читаются заголовки и адреса вкладок и что ничего не сохраняется и не отправляется, а вкладки не читаются, пока пользователь не нажал «Понятно». Это закрывает требование о раскрытии в самом продукте.

Ответы должны совпадать с [PRIVACY.md](../PRIVACY.md) и реальным поведением: расхождение считается нарушением.

## Вкладка Distribution

- Видимость: публичное; регионы: все.
- Платных функций нет.
- Форма может спросить статус trader / non-trader (требование ЕС). Выбор зависит от тебя; я не юрист.

## Порядок

1. Зарегистрироваться как разработчик: аккаунт Google, соглашение и разовый взнос (по моим сведениям $5, точную сумму покажет форма). Email разработчика потом изменить нельзя.
2. Add new item → загрузить `tab-search.zip`.
3. Заполнить Store listing, Privacy practices, Distribution.
4. Submit for review.

Срок проверки: по данным Google, обычно несколько дней, но может доходить до нескольких недель. Дольше смотрят новые расширения и нового разработчика, а разрешение `tabs` Google относит к чувствительным.
